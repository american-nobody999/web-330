**WEB 330 — Assignment 2.2 | JavaScript Closures**

## Welcome to The Grand Menagerie!

The assignment was simple: build a character generator using JavaScript closures.

The result? A vintage circus complete with animal characters, interactive selection cards, and personalized admission tickets.

VeriWhy Check had other ideas.

It wanted specific controls, exact output formatting, and predictable behavior. Our circus gave it a little more than it bargained for.

**Four checks. Two rounds of corrections. One very stubborn developer.**

In the end, all four checks passed without sacrificing the design.

## Lessons Learned

- Understand the testing contract before designing.
- Separate functional output from visual presentation.
- Preserve the learning objectives while exploring creative solutions.
- Automated tests can verify requirements without defining the limits of a project.
- JavaScript closures can protect private character data while providing access through getter functions.

## The Mission Going Forward
